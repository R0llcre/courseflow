# 课序易用性改进目标

目标：课程、讲义、阅读和作业在一个本地 App 内形成可直接使用的学习入口。

当前进度：0.3.0 已安装并完成正式 Mac 应用验收。修复透明文字与浅色背景数值错误，使用原生导航选择反馈，移除口号，资料按用途折叠，作业可直达文件、课程与精确作业页面。33 项测试通过，安装前后个人数据一致。详细证据见 VERIFICATION-0.3.md；0.2 的记录仅代表历史版本。

## 本轮验收

1. 点课程后显示该课程概览、材料与作业；列表和详情属于同一课程，不残留上一门课的任务。
2. 将七个课程空间现有本地资料打包进 App；文件按课程和用途分类，可搜索标题和正文，原文件保持不变。
3. PDF、图片、Markdown 和 notebook 可在 App 内阅读。预览失败必须有明确说明及打开原文件入口；文件链接不能假装存在。
4. 任务详情可以直接打开相关要求、阅读和已有成果；准备好文件不等于已提交。
5. 正文有标题、段落、表格与代码层次，长内容可滚动，图片可见，返回后保留课程和搜索位置。
6. 旧库的确认、笔记、个人计划和附件保留；新增课程内容通过独立资源目录装载，不直接写现有数据库。
7. 构建及核心测试通过，并在真实 Mac App 中验证课程切换、搜索、PDF、图片、notebook、返回和附件预览。

## 已发现的问题

- 课程列表某些入口只改变 selectedCourse，不清除旧 selectedTask，详情会显示另一门课程的任务。
- Course 模型只有基本名称及外链；课程资料没有独立目录。
- 外部材料 Link 直接跳浏览器；本地资料尚未内置，Quick Look 只接入手动附件。
- 作业要求全为低对比度的纯文本，长文没有阅读层次。
- “今天”中的最近事项、过期项目和无日期事项缺少清晰分组。

## 资料范围

打包现有课程文件及可从其来源明确识别的课程链接。未下载的在线资料明确标为在线入口；不将本地缺失冒充完整离线馆藏。平台核对时间保持原值。

## 设计

继续使用原生系统字体与现有浅灰底、白色正文和课程强调色。课程页首屏显示课程身份、安排和材料入口；作业与资料使用不同列表。正文使用主文字色、限制阅读宽度，提示与来源降为次级信息。缩略图仅来自真实文件内容。
